# Code of conduct

## Scope

This code applies to issues, pull requests, discussions and any other space associated with the
project.

## Expected behaviour

- Be precise and kind. Critique the work, not the person.
- State assumptions and evidence.
- Accept correction gracefully and correct the record publicly when you are wrong.
- Respect confidentiality and privacy. Do not post personal data, credentials or third-party
  confidential material.

## Unacceptable behaviour

- Harassment, discrimination, threats or personal attacks.
- Publishing private information without consent.
- Misrepresenting results, authorship or provenance.
- Deliberately introducing a security vulnerability or a hidden data collection mechanism.

## Enforcement

Report concerns to the maintainer through the contact in `SECURITY.md` or GitHub private reporting.
Reports are handled confidentially. The maintainer may edit or remove contributions, or block
participants, when this code is violated.
